# 隐私、授权与安全边界

## 上传前

确认文件是否包含个人信息、商业秘密、合同约束或第三方数据；能脱敏就先脱敏。

## 连接前

区分只读、写入、发送和付费动作，使用最小权限，先用测试数据验证可回滚性。

## 发布前

复核事实、引用、数字、收件人和附件；AI 生成的内容不要绕过人工审批直接对外发送。

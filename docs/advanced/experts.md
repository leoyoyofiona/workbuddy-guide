# 多专家并行协作

专家越多不一定越好。并行协作需要一个总目标、角色边界和统一的最终格式。

| 角色 | 负责 | 不负责 |
| --- | --- | --- |
| 研究 | 找资料、整理证据 | 替业务做最终决策 |
| 分析 | 比较、归纳、发现矛盾 | 编造缺失数据 |
| 编辑 | 组织结构、统一语气 | 修改事实来源 |
| 评审 | 按标准找问题 | 直接掩盖不确定性 |

# 任务拆解与计划

要求“一次完成所有事情”时，最容易出现范围漂移。先要求计划，再要求执行：

1. 复述目标和不做什么。
2. 列出输入缺口和风险。
3. 给出 3—7 个步骤，每步有产物。
4. 在高风险动作前暂停询问。
5. 最后按验收标准自检。

## 计划检查

如果一个步骤无法单独判断完成与否，就继续拆分；如果每一步都需要同一份输入，考虑先整理输入再执行。

# 外部信息调研

```text
请围绕【主题】完成一份调研。
范围：【地区、时间、对象】；优先使用可公开核验的来源。
输出：结论摘要、证据表、观点分歧、对我的业务可能有影响的 3 个问题。
不得把推测写成事实；每条关键结论附来源和日期。
```

先让它给出资料清单和研究计划，再确认范围后生成正文。

# CodeBuddy 内容的边界用法

腾讯官方资料中，CodeBuddy IDE/插件教程面向代码开发；WorkBuddy 官方页面向全场景办公。两者可以在“团队如何组织 AI 工作”层面互相启发，但入口、能力和产品承诺必须分开。

## 引用规则

- 写 WorkBuddy 页面时，优先链接 WorkBuddy 官方页。
- 引用 CodeBuddy 时，在标题和正文第一段明确产品名称。
- 不把 CodeBuddy 的指令、插件或 IDE 按钮描述成 WorkBuddy 的原生入口。

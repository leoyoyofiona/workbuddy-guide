# 内容创作与改写

创作和核验要分开。先让 WorkBuddy 提供方向，再用事实清单限制正文，最后按渠道检查格式。

## 案例：把内部活动通知改成公众号草稿

```text
受众：第一次参加活动的高校教师；渠道：公众号；目标：让读者完成报名。
事实输入：活动名称、日期、地点、报名链接、主办方原文。
第一轮：给出 3 个标题方向和各自适合的语气，不写正文。
第二轮：根据我确认的标题写 800 字以内正文，保留全部事实，不新增人数、效果和承诺。
第三轮：输出事实核对表、链接检查和需要人工确认的句子。
```

## 改写前后检查

| 项目 | 通过条件 |
| --- | --- |
| 受众 | 读者知道为什么与自己有关 |
| 行动 | 只有一个主 CTA，链接可点击 |
| 事实 | 日期、地点、名称和数字与原文一致 |
| 语气 | 不夸大，不把建议写成承诺 |
| 渠道 | 标题、段落和长度适合发布平台 |

## 常见返工

出现“行业领先、全面提升、百分之百”等没有来源的表达时，让 WorkBuddy 标记所有绝对化词语，再由人工决定删除、改弱或补证据。

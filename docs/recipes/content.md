# 内容创作与改写

```text
受众：【人群】；渠道：【平台】；目标：【阅读后行动】。
请先给 3 个标题方向，再写正文。
保留事实来源，不添加未提供的数字和案例；避免夸张承诺；最后列出需要人工确认的内容。
```

将“创作”和“事实核验”分成两步，降低流畅但不准确的风险。

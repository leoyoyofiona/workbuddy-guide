# 从主题到 PPT 结构

先要求“页级大纲”，不要直接生成几十页：

```text
受众：【谁】；目标：【让他们做什么决定】；时长：【分钟】。
请先输出 8 页以内的页级大纲，每页包含标题、核心结论、证据和建议视觉。
等我确认大纲后，再生成逐页讲稿和素材清单。
```

生成后重点核对数字、来源、图表单位和一页一个结论的节奏。

# 业务数据洞察

建议分三轮：先做数据质量检查，再做发现，最后做建议。

1. “告诉我字段、行数、时间范围、缺失和重复情况。”
2. “只根据数据列出 5 个可复核发现，并附字段依据。”
3. “针对发现提出行动建议，同时注明需要外部验证的假设。”

不要把 WorkBuddy 的文字总结当作统计检验或因果结论。

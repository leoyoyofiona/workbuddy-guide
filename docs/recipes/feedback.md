# 用户反馈与舆情分析

```text
请分析这批已脱敏的用户反馈。
先说明样本范围和缺失，再按主题归类；每类给出代表性原句编号、情绪倾向、问题严重性和建议行动。
不要把少量样本推断为全部用户；最后列出需要人工复核的分类。
```

输出建议要回到原文编号，避免“总结很像，但找不到证据”。

# 会议记录到行动清单

```text
请只根据以下会议记录输出：
1. 已做决定；2. 行动项（事项、负责人、期限）；3. 未解决分歧；4. 需要补充的信息。
原文没有写明负责人或期限时标记“待确认”，不要猜测。
```

发布前让参会者确认决策和负责人，尤其是由语音转写而来的专有名词。

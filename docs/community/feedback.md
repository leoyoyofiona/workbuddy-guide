# 反馈与问题报告

一条好的反馈可以被别人重现。请把“我打不开”改写成环境、入口、步骤、实际结果和期望结果。

## 最小复现模板

```text
页面或路由：
系统与浏览器：
WorkBuddy/Guide 版本或核验日期：
操作步骤：1… 2… 3…
实际结果：
期望结果：
官方来源或截图：
是否包含敏感信息：已脱敏/不适用
```

## 案例：报告 Safari 排版问题

不要只写“首页乱了”。请提供 Safari 版本、窗口 CSS 宽度、页面 URL、是否开启缩放、截图和发生问题的具体区域（例如标题折行、按钮溢出、横向滚动）。这样维护者才能区分字体、断点和浏览器缓存问题。

## 提交前检查

| 检查 | 做法 |
| --- | --- |
| 隐私 | 打码账号、文件名、客户名称和内部 URL |
| 复现 | 用无敏感信息的最小案例重跑 |
| 证据 | 保留版本、日期、截图和链接 |
| 影响 | 说明是阻断、错位、内容错误还是建议 |

推荐使用 GitHub Issues，或在仓库中提交 Pull Request。产品账号、下载或服务问题，请直接查看[WorkBuddy 官方页面](https://copilot.tencent.com/work/)的支持入口。

# 额度、套餐与功能边界

产品额度、套餐和活动会变化。记录这类信息时必须同时保存官方链接、核验日期、地区、账号类型和截图/提示原文。

## 不要这样写

“WorkBuddy 永久免费”“所有功能不限量”“某功能一定支持某格式”。

## 建议这样写

“截至核验日期，官方页面/客户端显示……；不同账号、地区和版本可能不同，请以当前提示为准。”

如果页面没有公开稳定证据，就只提供如何查看当前限制的方法。

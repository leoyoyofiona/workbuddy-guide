# 版本与更新记录

“当前能用”不等于“以后一直这样”。本指南把版本号和核验日期当成教程的一部分，避免读者拿旧截图判断新界面。

## 案例：更新后回归一个研究任务

1. 阅读官方更新日志，先标出可能影响文件、专家、Skills、连接器和产物的变化。
2. 在本机记录 WorkBuddy 版本、系统、账号类型和更新日期。
3. 用脱敏的固定样例重跑：输入文件 → 计划 → 证据表 → 摘要。
4. 对比旧记录：入口、字段、权限、产物格式、耗时和错误提示。
5. 只更新受影响页面，并在 source ledger 写明限制。

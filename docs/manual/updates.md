# 版本与更新记录

本指南的每篇事实性页面都有 `verifiedAt`；涉及本机界面的页面还会记录 `testedVersion`。

## 更新流程

1. 先看 WorkBuddy 官方产品页是否出现平台、能力或下载变化。
2. 在本机记录版本并重跑关键流程。
3. 更新 `docs/_meta/source-ledger.yml` 和页面 frontmatter。
4. 检查可能受影响的链接、截图、FAQ 和实战配方。
5. 在本页记录变化和限制，不删除历史证据。

## 当前核验批次

本网站首批内容核验日期为 2026-08-10；本机实测页面注明 WorkBuddy 5.3.11。

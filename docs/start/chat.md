# 看懂对话与工作区

把 WorkBuddy 看成一个任务工作台，而不是只会回答问题的聊天框。你要持续关注三个区域：

| 区域 | 你要看什么 |
| --- | --- |
| 输入 | 目标、材料、限制、交付格式是否完整 |
| 过程 | 是否拆解任务、调用了哪些能力、哪里需要确认 |
| 产物 | 文件、表格、报告或演示文稿是否可检查 |

## 一个好习惯

每次发送指令前先写一句“完成标准”。例如：“输出一页可以直接发给团队的摘要，包含结论、证据和待办”。

## 不要忽略人工确认

涉及外部发布、敏感文件、业务决策和费用的步骤，先暂停检查来源和权限，再继续执行。

# 产物与交付检查

一份结果只有在别人能理解、编辑、复核和继续使用时，才算交付。

## 交付四问

- 受众是谁？他们需要先看到什么？
- 结论和证据是否分开？
- 文件格式是否适合下一步工作？
- 哪些内容需要人工签字、发布或确认？

## 推荐指令

```text
请先给出交付物目录，再生成正文。
每个结论都附上来源或“需要确认”标记；完成后列出你没有完成的要求。
```

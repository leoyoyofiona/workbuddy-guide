# 认识 AI 专家团

“多专家”不是让你堆砌角色名称，而是把任务拆成不同的专业视角，再要求它们汇总为一个交付物。

## 任务写法

```text
目标：为下周的产品评审准备一页决策摘要。
请先由研究角色整理证据，再由产品角色提炼选项，最后由编辑角色合并成：背景、发现、建议、待确认问题。
只使用我提供的资料，冲突信息列在“待确认”中。
```

## 什么时候值得用多专家

- 输入材料来自不同来源，需要交叉整理。
- 同一个结果同时需要研究、设计和表达。
- 你希望看到不同角色的检查意见。

任务越小，越适合直接使用单轮清晰指令。

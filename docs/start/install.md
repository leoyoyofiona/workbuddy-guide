# 安装与账号准备

WorkBuddy 官方页面提供 macOS 与 Windows 下载入口，也介绍了桌面端、主流 IM 和小程序等使用形态。不要从搜索结果中的第三方安装包开始。

## 安装前检查

- 打开[官方产品页](https://copilot.tencent.com/work/)，从“下载 WorkBuddy”区域选择系统版本。
- 确认磁盘空间、网络和登录方式可用。
- 如果是公司设备，先确认是否允许安装桌面 AI 工具、上传工作文件或访问外部网络。

## 第一次打开

1. 完成安装并启动客户端。
2. 观察欢迎页、对话入口、文件引用方式和产物区域。
3. 不要一开始就上传敏感客户资料，先用脱敏文本测试。
4. 记录客户端版本，后续遇到差异时一并反馈。

## 验收

你能打开 WorkBuddy、进入对话、发送一条不含敏感信息的指令，并看到明确的响应或任务状态。

# 快速上手 FAQ

## 我应该从什么任务开始？

从输入明确、结果容易检查、失败成本低的任务开始，例如整理公开资料或生成会议待办。

## 为什么结果看起来很完整但不可靠？

因为“完整”不等于“有依据”。要求它列出来源、标记不确定项，并对关键数字逐条复核。

## 能不能直接上传公司文件？

先确认公司政策、文件敏感级别、服务条款和当前客户端的权限提示。不要把学习任务当成安全审批。

## 遇到功能找不到怎么办？

记录客户端版本、系统、入口、操作步骤和截图，再查看[故障排查](/advanced/troubleshooting)并通过[反馈页](/community/feedback)提交。

# 快速上手 FAQ

## 我应该从什么任务开始？

选择输入明确、结果容易检查、失败成本低的任务，例如公开资料整理、脱敏会议记录和简单表格检查。先完成“可复核的小交付”，再尝试长报告或外部连接。

## 为什么结果完整但不可靠？

模型可能把缺失信息补得很顺。要求它列出来源、时间、假设和不确定项；对数字、姓名、金额和政策逐条回到原文核对。

## 能不能直接上传公司文件？

先确认组织政策、文件敏感级别、服务条款、账号类型和客户端权限提示。不能因为产品支持文件处理，就推断所有公司文件都允许上传。学习阶段用脱敏副本。

## Skill、专家、专家团有什么区别？

Skill 解决一种重复能力；专家提供角色、方法和工具链；专家团把多个角色组合到一个复杂任务。先看任务是否真的需要多角色，不要为了“看起来高级”增加协作。

## MCP/连接器什么时候用？

当任务必须访问外部数据或工具时才考虑。先确认只读/写入权限、数据流、授权对象、日志和撤销办法；涉及发送、改库或费用时必须人工确认。

## Credits、额度和价格怎么判断？

不要引用旧截图或第三方帖子。打开当前官方页面或客户端的计费提示，记录地区、账号、时间和原文；动态限制见[额度手册](/manual/limits)。

## 遇到功能找不到怎么办？

记录版本、系统、账号类型、入口路径、最小复现步骤和截图。先看[故障排查](/advanced/troubleshooting)，再通过[反馈页](/community/feedback)提交；不要连续重复点击或上传敏感日志。

## 一分钟案例：结果和别人不一样

同事说“我这里有专家入口”，你却看不到。不要先判断谁对谁错，按顺序记录：系统与版本 → 账号类型 → 进入路径 → 是否完成授权 → 页面截图。然后用同一条无敏感信息的最小任务测试。如果只有入口不同，反馈时把差异写成表格，维护者才能判断是版本、权限还是配置差异。

<div class="wb-callout"><strong>记住：</strong>“没有看到某个按钮”不等于功能不存在，也不等于你有权限使用。先记录证据，再判断是版本、账号、入口还是权限问题。</div>

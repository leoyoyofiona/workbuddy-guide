# Skills 与能力扩展

Skill 的价值是把一套稳定的工作方法写下来，让后续任务少重复解释。它不是“让 AI 永远正确”的开关。

## 一个 Skill 至少要写清楚

1. 适用场景：什么时候调用。
2. 输入要求：需要哪些文件、字段或上下文。
3. 执行步骤：先做什么，遇到不确定怎么办。
4. 输出格式：标题、表格、文件或检查清单。
5. 禁止事项：不能访问什么、不能编造什么。

## 发布前自测

用两个正常样例和一个缺失材料样例测试。后者必须能礼貌地停下来提问，而不是生成一份看似完整的假结果。

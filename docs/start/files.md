# 文件、引用与产物

文件不是“扔进去就结束”。每次上传前先确认来源、权限、敏感字段和期望产物。

## 安全输入清单

- 删除身份证号、手机号、客户合同号等不必要信息。
- 说明文件用途和时间范围，避免让模型自行猜测上下文。
- 指定“只使用提供的文件”，要求无法找到依据时标记待确认。
- 对生成的表格、报告、PPT 做人工抽样核对。

## 产物验收

检查格式是否可编辑、引用是否对应原文、数字是否能回溯到输入文件，以及是否遗漏了任务要求。

# 案例库：先做一件小事

这里不要求你背定义。每个案例都只有一条主线：**看图 → 照做 → 检查 → 再复用**。先挑一个和你今天工作最像的案例，做完再往下走。

## 每个案例都用同一个小习惯

<div class="wb-beginner-rules"><div><strong>1. 先少量</strong><span>一条文字、一个文件、两份样本。</span></div><div><strong>2. 说人话</strong><span>告诉它目标、材料和你想要的格式。</span></div><div><strong>3. 看结果</strong><span>不满意就指出一处具体问题。</span></div><div><strong>4. 再复用</strong><span>稳定后才做批量或自动化。</span></div></div>
